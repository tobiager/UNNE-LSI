## Estructura de INTERNET

```
El objetivo de Internet no es otro que conectar los sistemas terminales entre sí.
```
- Los sistemas terminales acceden a Internet a través de los ISP
- Proporcionan acceso inalámbrico (WiFi) en aeropuertos, hoteles, cafeterías y otros lugares
    públicos.
- Los ISP de datos móviles, proporcionan acceso móvil a nuestros teléfonos.
- Cada ISP es en sí mismo una red de conmutadores de paquetes y enlaces de comunicaciones.
    Proporcionan acceso a Internet a los proveedores de contenido, conectando sitios web y
    servidores de vídeo directamente a Internet.
- Estos ISP de nivel inferior se interconectan a través de ISP de nivel superior nacionales e
    internacionales, se componen de routers de alta velocidad interconectados a través de enlaces
    de fibra óptica de alta velocidad.


```
− las redes de proveedores de contenido (Google, Microsoft, Amazon) pueden ejecutar su propia red
para acercar los servicios y el contenido a los usuarios finales.
```

## Estructura de INTERNET


```
¿Qué es un IXP?
```
```
Los IXPs (Internet eXxchanges Points) son componentes fundamentales de la Red Internet.
```
```
− A través de un IXP, se produce el intercambio de tráfico entre las redes de diversas entidades
(operadores, proveedores de acceso, organismos de gobierno, entidades académicas, etc.)
```
```
− Estos puntos neurálgicos de la Red se han construido en todo el mundo bajo distintos esquemas
institucionales, topológicos y operacionales.
```
```
− Persigue idénticos objetivos: eficientizar el ruteo de Internet, mejorando la calidad de servicio y
minimizando los costos de interconexión.
```
```
− Todos los IXPs CABASE siguen el modelo cooperativo. Todos los miembros de los IXPs CABASE,
son socios de la Cámara Argentina de Internet que tienen como objetivo mejorar la calidad en las
comunicaciones y reducir costos.
```

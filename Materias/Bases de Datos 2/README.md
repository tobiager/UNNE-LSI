# Bases de Datos II – UNNE 2026

Este repositorio reúne **prácticos, parciales, cuestionarios de teoría, modelos y monografías** de la materia **Bases de Datos II** de la **FaCENA - UNNE**.
Incluye material de distintos años (por ejemplo, 2020 y 2023), además de recursos para la cursada 2026.

---

## 📦 Estructura del Repositorio

| Carpeta/Archivo | Contenido |
|---|---|
| `Practicos/` | Prácticos y resoluciones (activas, distribuidas, objeto-relacionales, OLAP) |
| `Parciales/` | Enunciados/modelos y resoluciones; incluye PDFs de cuestionarios de teoría |
| `Monografias/` | Monografías e informes de minería de datos (exploración, limpieza, selección, transformación) |
| `Laboratorio/` | Informes de laboratorio (compilados por grupo) |
| `modelos/` | Modelos de parciales, teoría, cuestionarios y pregunteros (material de apoyo) |
| `2020/` | Material histórico (principalmente monografías y documentos) |
| `2023/Practicos/` | Prácticos 2023 en DOCX/PDF |
| [Preguntero BDD2.pdf](Preguntero%20BDD2.pdf) | Preguntero (PDF) |
| [preguntero.pdf](preguntero.pdf) | Preguntero alternativo/extra (PDF) |

## 🚀 Temario (enfoque práctico)

- **Bases de Datos Activas**
- **Bases de Datos Distribuidas**
- **Bases de Datos Objeto-Relacionales**
- **OLAP y análisis multidimensional**
- **Minería de Datos** (fases: exploración, limpieza, transformación, selección)
- **SQL Avanzado** (triggers, procedimientos, consultas complejas)
- **Diseño y normalización avanzada**

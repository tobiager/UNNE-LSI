## 🚀 Temas principales y conceptos aplicados

- **Procesos de software avanzados**

- **Modelado UML** (diagramas de casos de uso, clases, secuencia, actividades)
- **Metodologías Ágiles aplicadas a proyectos**
- **Gestión de calidad y pruebas de software**
- **Trabajo de campo / proyecto**: aplicación práctica de lo visto en la materia
